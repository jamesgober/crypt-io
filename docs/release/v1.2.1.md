# v1.2.1 — Feature-Set Docs

**Release date:** 2026-10-23
**Status:** stable patch release. Documentation only: no code, public
API or wire-format change.

---

## What this release is

`cargo doc` with `RUSTDOCFLAGS="-D warnings"` failed for most feature
sets other than the default set and `--all-features`. The failures
were intra-doc links in prose that names items from more than one
feature: the `hash` and `mac` algorithm tables, the crate overview,
the `aead` and `stream` overviews, and a few item docs that point at
an item behind another feature (for example `Crypt::decrypt` linking
`decrypt_zeroizing`, or `StreamDecryptor` linking `StreamEncryptor`,
which needs a random source).

The links have been there since 1.1.0. CI only built the docs with
every feature, so it never saw them. They showed up while checking
1.2.0 with the feature set bouncer-io uses,
`default-features = false, features = ["zeroize", "mac-blake3"]`.

Nothing changes for docs.rs, which builds with every feature: every
link is still there.

---

## How the links work now

- **Reference text** (tables, "see X", "the inverse of X") links its
  target only when that target is compiled in, and shows plain code
  text otherwise. The `hash` and `mac` tables always list every
  algorithm with its feature, linked where the feature is on.
- **Prose about feature availability** (the crate's "Platform
  support" list, the `aead` "Without a random source" section)
  names the gated items in plain code text, like the items next to
  them already did.
- The sealed-format constants now link `Crypt::open`, which every
  AEAD build has, instead of `Crypt::seal`.

The `aead` module docs also now say that `generate_key` needs the
`zeroize` feature as well as a random source.

---

## Other changes

- The README linked to `.dev/ROADMAP.md`, which is not part of the
  repository, so the link was dead on GitHub and crates.io. It is
  removed.
- CI has a new Linux job that builds the docs with `-D warnings` for
  eight partial feature sets, including no features at all,
  `zeroize,mac-blake3`, and a `no_std` set without a random source.
